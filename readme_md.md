## 🌟 Overview

**NEON DRIFT** is a retro-futuristic arcade game featuring smooth mechanics, dynamic power-ups, procedural sound synthesis, and eye-catching visual effects like chromatic aberration and particle shockwaves. 

Dodge dangerous asteroids, collect score multipliers, trigger slow-motion fields, and dash through intense hazards—all powered by pure Python!

---

## ✨ Features

- **⚡ Procedural Audio Synthesis:** Real-time 8-bit sound effect generation using `numpy` & `pygame.sndarray`—no external audio files required!
- **🚀 Dynamic Dash Mechanic:** Temporary invulnerability burst paired with expanding neon shockwaves.
- **💥 Visual Effects (Juice & VFX):** 
  - Chromatic Aberration (RGB shift) on collision.
  - Screen Shake & Hyperspace Starfield Boost during speed bursts.
  - Interactive synthwave horizon grid with dynamic perspective.
- **🎁 Power-Ups & Hazards:**
  - 🪙 **Coins & Combo System:** Chain coin pickups to build up to a 9x score multiplier.
  - 🛡️ **Shield Orbs:** Restore lost shields/lives.
  - ⏱️ **Slo-Mo:** Slows down enemy spawn velocity temporarily.
  - ✖️ **2X Multiplier:** Doubles all score gain for a limited duration.
  - ⚡ **Zig-Zag Hazards:** Unpredictable wave-motion obstacles.

## 🛠️ Installation & Setup

### Prerequisites

Ensure you have Python 3.8 or higher installed on your system.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/neon-drift.git
cd neon-drift
```

### 2. Install Dependencies

Install the required Python libraries using `pip`:

```bash
pip install pygame numpy
```

### 3. Run the Game

```bash
python neon_drift.py
```

## 🎮 Controls

| Key | Action |
| :--- | :--- |
| **A / D** or **← / →** | Move Left / Right |
| **Space** / **W** / **↑** | Perform Dash (Invulnerability Burst) |
| **P** or **Esc** | Pause / Resume Game |
| **Enter** | Start Game / Restart |
